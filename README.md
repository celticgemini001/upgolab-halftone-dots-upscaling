# Halftone Dots Under Upscaling: The Dot Lattice Scales Exactly, and Descreening Costs You 1.1–1.3× the Pitch

A screened print carries a dot lattice at a fixed pitch. Measured across 5 pitches and 4 resamplers: the lattice frequency scales to within 0.56%, nearest-neighbour bloats fractional factors by 3.2×, and killing the dots needs a filter that blurs an edge to 1.1–1.3× the dot pitch.

## About this repo

This repository exists to serve one measured article. Every number in it came from
ffmpeg and numpy run on real files on this machine — the commands are in the page so
you can re-run them and get the same rows. Where the measurement contradicted the
hypothesis, the page says so.
